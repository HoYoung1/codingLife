② 서비스 플로우 — AI 어시스턴트 질의 (Sequence Diagram)

사용자가 질문을 입력하면 Orchestrator가 의도를 분류하고, 해당 전문 Agent가 Tool Calling 루프를 통해 데이터를 조회해 답변을 생성합니다.

sequenceDiagram actor 사용자 participant UI as 💬 Streamlit UI participant ORCH as 🧠 Orchestrator participant LLM1 as GPT-4o-mini
(Intent) participant AGENT as 전문 Agent
(Card/Contract/Training) participant LLM2 as GPT-4o-mini
(Tool Calling) participant TOOL as 🔧 Tool participant DATA as 💾 데이터 사용자->>UI: 질문 입력
"30일 내 만료 카드 알려줘" UI->>ORCH: run_pmo_agent(query) ORCH->>LLM1: 의도 분류 프롬프트 LLM1-->>ORCH: "card" ORCH->>AGENT: run_access_card_agent(query) loop Tool Calling 루프 (최대 10회) AGENT->>LLM2: 시스템 프롬프트 + 질문 LLM2-->>AGENT: tool_calls 반환
[check_expiring_cards] AGENT->>TOOL: tool.invoke(args) TOOL->>DATA: access_cards.csv 조회 DATA-->>TOOL: 카드 데이터 반환 TOOL-->>AGENT: ToolMessage (결과) AGENT->>LLM2: 메시지 이력 + ToolMessage LLM2-->>AGENT: 최종 답변 (tool_calls 없음) end AGENT-->>ORCH: 답변 텍스트 ORCH-->>UI: 답변 반환 UI-->>사용자: 마크다운 렌더링

③ 서비스 플로우 — 종합 리포트 A2A (Sequence Diagram)

Report Agent가 Access Card / Contract / Training Agent를 순차 호출(A2A)하고, GPT-4o로 통합 분석 리포트를 생성합니다.

sequenceDiagram actor 사용자 participant UI as 📋 종합 리포트 페이지 participant REP as 📋 Report Agent participant ACA as 🪪 Access Card Agent participant COA as 📄 Contract Agent participant TRA as 📚 Training Agent participant LLM_R as GPT-4o
(종합 분석) 사용자->>UI: "리포트 생성" 클릭 UI->>REP: run_report_agent() Note over REP,ACA: A2A 호출 ① REP->>ACA: "전체 출입카드 현황 요약" ACA-->>REP: 카드 현황 텍스트 Note over REP,COA: A2A 호출 ② REP->>COA: "전체 계약·60일 내 만료 계약" COA-->>REP: 계약 현황 텍스트 Note over REP,TRA: A2A 호출 ③ REP->>TRA: "전체 교육 출석률 현황 요약" TRA-->>REP: 교육 현황 텍스트 REP->>LLM_R: 시스템 프롬프트 + 3개 Agent 결과 LLM_R-->>REP: 종합 현황 리포트 (Markdown) REP-->>UI: {card, contract, training, report} UI-->>사용자: 탭별 결과 표시
