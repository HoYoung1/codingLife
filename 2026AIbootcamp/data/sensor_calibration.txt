센서 교정 및 유지보수 지침서
문서번호: QM-SEN-005 | 개정: Rev.2

1. 인라인 파티클 카운터(IPC) 교정 주기
- 정기 교정: 매 3개월 1회 (외부 교정 기관 의뢰)
- 일상 점검: 매일 영점(Zero Count) 확인
- 교정 기준값: 청정 N2 환경에서 0.3μm 파티클 ≤ 2 ea/ft³

2. 드리프트(Drift) 허용 범위
센서 값이 실제 환경과 지속적으로 편차를 보이는 현상을 드리프트라 한다.
- 허용 드리프트: ± 0.002 (절대값 기준)
- 드리프트 초과 시: 즉시 교정 또는 교체

3. 센서 오류 식별 방법
3.1 단일 Spike 패턴
  - 1개 데이터 포인트만 급등하고 이후 정상 복귀 시 센서 오류 의심
  - 대응: 동일 패턴 2회 이상 반복 시 교정 실시

3.2 고착(Stuck) 값
  - 동일한 값이 3개 측정점 이상 연속으로 동일하면 센서 고착 의심
  - 대응: 센서 전원 리셋 후 재측정

3.3 음수(Negative) 값
  - 물리적으로 불가능한 음수 출력 시 하드웨어 오류
  - 대응: 즉시 센서 교체, 해당 측정 데이터 무효 처리

4. 온도/습도 센서 (SENSOR_TEMP, SENSOR_HUMIDITY)
- 챔버 온도 정상 범위: 22 ± 1 ℃
- 챔버 습도 정상 범위: 45 ± 5 %RH
- 온도 이상 시 파티클에 영향: 온도 +2℃ 상승당 파티클 약 15% 증가 경향

5. 압력 센서 (SENSOR_PRESSURE)
- 챔버 정상 압력: 5.0 ± 0.2 mTorr
- 압력 이상 시 파티클과의 상관관계: 압력 불안정 → 배기 시스템 역류 → 파티클 상승 가능

6. 센서 데이터 품질 관리
- 결측치(Null) 발생 시: 직전/직후 평균값으로 보간 처리 가능 (최대 2개 연속 결측 허용)
- 이상치 탐지: 3시그마(σ) 이상 벗어난 값은 이상치 플래그 부여
- 데이터 보관: 원본 데이터 1년, 집계 데이터 3년 보관
